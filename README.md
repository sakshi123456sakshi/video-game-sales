  **🖥️ Project Overview**

This dashboard provides an interactive, visual, and data-driven analysis of global video game sales, helping uncover key industry trends.

**1 Overview Tab**<br>

◦ Displays total games, total sales, and median sales by region.<br>
◦ Highlights Top 10 games and publishers based on total global sales.<br>
◦ **Insight**: Shows how specific publishers and genres dominate the global market, revealing historical and modern bestsellers.

**2 Platform Analysis Tab**<br>

◦ Compares total sales by gaming platforms (e.g., PS4, Xbox, Switch, PC).<br>
◦ Displays lifetime sales trends for major consoles.<br>
◦ **Insight:** Identifies which platforms consistently drive high sales across different regions and years.

**3 Genre Insights Tab**<br>

◦ Analyzes sales distribution by genre (Action, Sports, Shooter, Role-Playing, etc.).<br>
◦ Includes bar and pie charts for global vs. regional preferences.<br>
◦ **Insight:** Certain genres perform better in specific markets — for example, Sports in Europe, Action in North America, and Role-Playing in Japan.

**4 Regional Sales Tab**<br>

◦ Visualizes sales across North America, Europe, Japan, and Other Regions.<br>
◦ Includes interactive choropleth maps showing geographic dominance.<br>
◦ **Insight:** Reveals how cultural and regional preferences impact the success of games and platforms.

**5 Publisher Trends Tab**<br>

◦ Displays top publishers by total sales and average game success rate.<br>
◦ Compares annual performance trends for leading publishers (e.g., Nintendo, EA, Activision).<br>
◦ **Insight:** Some publishers maintain consistent performance across decades, while others dominate specific console generations.

🚀 **How to Run**
- **Clone the repository**
git clone https://github.com/sakshi123456sakshi/video-game-sales.git

- **Navigate to the project folder**
cd video-game-sales

- **Install dependencies**
pip install -r requirements.txt

- **Run the Streamlit app**
streamlit run main.py

- Open the displayed URL in your browser to explore the dashboard.
