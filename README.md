This project focuses on analyzing global video game sales data to uncover insights about sales trends across different platforms, genres, regions, and publishers. Using Python, data cleaning, preprocessing, and exploratory data analysis (EDA) were performed on a large dataset to make informed business and gaming insights.

Technology Stack
Programming Language: Python
Libraries: pandas, numpy, plotly, matplotlib, seaborn, streamlit
Deployment: Streamlit

Check out the interactive dashboard here: [Live App](https://video-game-sales-u48ddmilibeepoh7l6kdgm.streamlit.app/)
