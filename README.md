📊 **Project Name:** Global Video Game Sales Analysis
-------------------------------------------------------------------------------------------------------------------------------------------------
🎮 **Global Video Game Sales Analysis Dashboard**
A Streamlit dashboard designed to analyze global video game sales data — uncovering insights about platforms, genres, regions, and publishers.
This interactive dashboard helps developers, marketers, and gaming enthusiasts explore patterns in game popularity, regional sales performance, and market trends.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
🔗 **Live Demo**
- Check out the interactive dashboard here: [Live App](https://video-game-sales-u48ddmilibeepoh7l6kdgm.streamlit.app/)
----------------------------------------------------------------------------------------------------------------------------------------------------------------------
🛠️ **Technologies Used**
- **Language:** Python
- **Framework:** Streamlit
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Plotly, Matplotlib, Seaborn
- **IDE / Environment:** VS Code, Jupyter Notebook, Anaconda
---------------------------------------------------------------------------------------------------------------------------------------------------------------------
🚀 **How to Run**
- **Clone the repository**
git clone https://github.com/sakshi123456sakshi/video-game-sales.git

- **Navigate to the project folder**
cd video-game-sales

- **Install dependencies**
pip install -r requirements.txt

- **Run the Streamlit app**
streamlit run main.py

- Open the displayed URL in your browser to explore the dashboard.
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
📊 **Dataset**
- The dataset contains detailed information about global video game sales, including:
- Name of Game
- Platform (e.g., PS4, Xbox, PC)
- Genre
- Publisher
- Sales Data ( North America, Europe, Japan, and Other Regions)
- Global Sales (in millions)
